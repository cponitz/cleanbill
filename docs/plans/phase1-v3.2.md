## 2. Scope

### 2.1 Goal (v3.2)
Phase 1 in two stages. **Stage 1 (the gate):** Clean Bill everywhere with one design system behind the site, the letters, the packet and the e-mails; an operator console at `/ops` that runs the whole daily loop without SQL or the Mac. **Stage 2 (after the gate):** card on file, outbound e-mail, the Lob batch, cut-over — unchanged from v3.1. Exit gate for Phase 1 is unchanged: a real matching property produces `ready_to_submit` on cleanbillco.com with a card saved; an approved e-mail sends from hello@cleanbillco.com; a test letter arrives from Lob carrying a `CB-` code and a QR to cleanbillco.com; Lighthouse ≥ 90 mobile; Charlie runs the walkthrough from `/ops` alone. Dates that hold: design review Sep 26 (on `/design-system` and the site) · friend walkthrough Oct 1–2 · 1,000 pieces to Lob Oct 5 — see the capacity note in §3 for what the gate does to Oct 5.

Repo is the only source of truth for code; Supabase deployed only from `main`; agent stays in shadow mode; a charge happens only after an observed refund + notice (B-13) — nothing in Phase 1 charges; findings are structured; DL numbers masked, images purged; refund figures rounded down; validation rules exist twice and change together from the shared fixture; copy files change wording only from an approved spec; **after R5, brand values exist once, in `tokens.css`, and every surface reads them.**

## 7. Glossary
**API** application programming interface · **App Router** Next.js's page/route system · **ADR** architecture decision record (`docs/adr/`) · **B-nn / O-nn / T-nn / G-nn** business decision / open decision / technical decision / gap-register item · **CI** continuous integration · **Claim code** the random `CB-XXXX-XXXX` credential printed on a letter · **Component sheet** the named CSS classes every page is built from · **Contrast ratio** the WCAG measure of text legibility · **Deno** the runtime for Supabase edge functions · **Design system** tokens, themes, components, assets, a living style guide and a written guide, versioned in the repo (SPEC-08 Part C) · **DL** driver's license · **DPS** Texas Department of Public Safety · **Edge function** a small server program on Supabase at a public URL · **Findings** structured validation results `{code, severity, field, message, detail}` · **Gate G** the checkpoint in §3 that must be fully Met before Stage 2 · **gh** GitHub's command-line tool · **HEIC** the iPhone photo format · **Lighthouse** Google's page-quality scorer · **Lint** an automated check that fails the build on a rule violation · **Lob / Resend / Stripe** print-and-mail API / e-mail API / payments API · **M8** the copy-review item from the Sep 14 memo · **Migration** a versioned SQL file that changes the schema · **OFL** SIL Open Font License · **Open Graph image** the preview picture shown when a link is shared · **PAN** primary account number (the card number) · **Payment Element / SetupIntent** Stripe's card form / save-now-charge-later object · **PR** pull request · **Preview deploy** Vercel build of a branch at its own URL · **Primitive / semantic token** a raw value (`--teal`) / a purpose-named alias (`--color-primary`) · **Root Directory** the sub-folder Vercel builds from · **Schema parity** `supabase db diff --linked` is empty · **Selftest** the one-URL end-to-end health check · **Shadow mode** the agent drafts, a human approves · **Situs** the property's physical address · **SPEC-nn** a feature handoff in `docs/specs/` · **Style guide (living)** `/design-system`, a page that renders the design system from its own tokens · **TCAD** Travis Central Appraisal District · **Theme** a file of primitive values the whole site switches to at once · **Token** a named design value read by every component · **Typed pre-check** the customer types their license address before the photo · **WCAG 2.2 AA** the accessibility standard the site meets · **§11.43(j)** the license copy must accompany the application · **§41.0051** Property Code advertisement disclaimer rule.
