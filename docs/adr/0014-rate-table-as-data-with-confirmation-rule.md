# ADR 0014: rate table as data with a confirmation rule

- **Date:** 2026-09-13
- **Status:** Accepted
- **Handbook ID:** (SPEC-01; no T-nn yet)

## Decision

Tax rates and exemption rules live in `trd/estimator/rates/units.json`, one entry per TCAD entity code and tax year,
generated by `trd/estimator/build_units.py` from three public inputs: the Travis County Tax Office truth-in-taxation
summary (adopted rate per unit, five years), TCAD's annual Exemption Listing Report (per-unit state amount,
local-option percent/minimum/amount, freeze ceiling), and the certified roll's `PROP_ENT` file (assessed minus taxable
on homestead-only accounts, used only to cross-check the listing). Hand-verified figures for earlier years sit in a
small `RESEARCHED` table inside the builder with their sources.

Each figure carries `confirmed`: true when it comes from a primary source for that tax year, from statute (school
amounts), or is an assumption that can only understate a refund (a unit with no exemption in the listing is assumed
to have had none earlier). A local-option percentage or amount carried back from the listing year to an earlier year
could overstate, so it stays unconfirmed until sourced. A lead touching any unconfirmed figure for any refund year is
`estimate_unconfirmed` and excluded from batch selection.

## Rationale

Refund figures printed in a §41.0051-regulated advertisement must be right for the property they are printed on, and
only ~40% of Tier-1 leads are in the City of Austin. Data beats code for 146 taxing units that change every autumn;
the builder makes the provenance reproducible; the confirmation rule makes "we might be overstating" a queryable flag
rather than a judgment call at mail time. TCAD's prior-year listings (2024, 2025) are not online, which is why the
carry-back rule exists.

## Revisit when

TCAD publishes prior-year listings (add them as `--listing` inputs per year), the 2026 rates are adopted (G-31), or
prior-year appraised values arrive (G-27 / property_values).
