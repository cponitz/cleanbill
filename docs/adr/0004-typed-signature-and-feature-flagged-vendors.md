# ADR 0004: typed signature and feature flagged vendors

- **Date:** 2026-09-06
- **Status:** Accepted (partially superseded by 0012)
- **Handbook ID:** T-04

## Decision

Typed e-signature with an ESIGN audit block instead of an e-sign vendor; Stripe, Lob and Resend behind feature flags.

## Rationale

Removed every human-dependent setup step from the prototype week. The 'Edge Functions instead of Next.js' half of the original decision is superseded by ADR 0012.

## Revisit when

Revisit if the attorney requires a vendor e-signature.
