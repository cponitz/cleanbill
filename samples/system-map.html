Architecture

Three lanes. The lead lane runs in batch from the appraisal roll. The claim lane is what a homeowner touches and takes about ten seconds end to end. The background lane never sends anything — the agent drafts, you approve.

The two things that make it safe to test

Shadow mode: the agent and process-claim write drafts and statuses, never emails, filings, or charges. And the test property (account 999000001) is synthetic — nothing you do with TRD-TEST-0001 touches a real homeowner. Real leads use real accounts, so don't submit claims against those unless you mean it.

Walk-through, in claim order

Do these top to bottom the first time; after that each step stands alone. You marks steps only you can do; Claude marks ones I run on request.

  1. Open the public site and enter the test code

    The landing page is what a homeowner sees if they type the address from the letter instead of scanning the QR.

    Expect: typing trd-test-0001 (any case) lands on the claim page for 3675 DUVAL ST with a $4,500 estimate ($2,000 for 2024, $2,500 for 2025, about $2,500/yr going forward) and the February 1, 2027 deadline.

  2. Read the claim page and the service agreement as a homeowner would

    This is the copy that needs your review (task C5): the fee disclosure, the "you can file free yourself" line, the §41.0051 refund disclosure, and the agreement's twelve clauses. The agreement pulls the property and tax years from the same API.

  3. Submit a test claim You

    Happy path — download the synthetic license below (Richard L Garcia, 3675 Duval St — it matches the test property), fill the name as Richard L Garcia. Result: ready_to_submit with a filled Form 50-114.

    Mismatch path — use a photo of your own license. Result: needs_dl_update with a draft asking the homeowner to update their DPS address. (Your license image is stored encrypted in a private bucket, the number is masked in the database, and the purge job deletes images 30 days after filing.)

    claim.html?c=TRD-TEST-0001 synthetic license id_03.jpg
    Expect: "Done — we have everything, Richard." A second visit to the same link shows "This claim is already in progress" — one code, one claim. Reset it in step 9.

Glossary

TCAD Travis Central Appraisal District, which values property and administers exemptions and publishes the roll we parse · Roll the certified list of every property, owner, value and exemption flag · Form 50-114 the Texas Comptroller's residence homestead exemption application · DL / DPS driver's license / Texas Department of Public Safety, which issues it · §41.0051 the Texas Property Code rule requiring the "advertisement of services" disclaimer on solicitations · API application programming interface — an address that returns data for a page's JavaScript instead of a page · Edge function a small server program hosted by Supabase at a public address · CORS the browser rule that lets a page on one domain call an API on another · Supabase hosted Postgres database, file storage and edge functions · GitHub Pages / Actions GitHub's free static hosting from a repo folder / its free scheduled job runner · MCP the connector Claude uses to operate Supabase directly · DuckDB a local analytics database used to query the roll fast · ETL extract-transform-load, the roll-to-database pipeline · Shadow mode the agent drafts; a human approves before anything is sent · Signed URL a temporary, expiring link to a private file · Haiku 4.5 / Sonnet 5 the Claude models used for reading licenses (fast, cheap) and for the agent (reasoning) · pdf-lib the library that fills the PDF form fields.
